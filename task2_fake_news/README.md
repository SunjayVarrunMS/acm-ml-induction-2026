# Fake News Detection

Binary classifier (Fake / Real) trained on the ACM ML fake-news dataset, with an inference mode for unseen articles.

## Approach

Bidirectional LSTM over a learned embedding (`Embedding → BiLSTM(64) → BiLSTM(32) → Dense → Dropout → Dense(sigmoid)`), chosen over fine-tuning BERT for speed. Trains in a couple of minutes on a Colab GPU rather than a much longer fine-tuning run.

## How to run

Run locally (Python 3.12, CPU, no GPU needed for this LSTM at this dataset size) or in Colab; the notebook in this repo already has all cells executed with real outputs. `train.csv`/`test.csv`/`evaluation.csv` sit right next to the notebook and are semicolon-delimited (`sep=';'`). To reproduce: open in Jupyter/Colab and run all cells top to bottom.

## Results

Held out `test.csv` (8,117 rows), positive class = Fake:

| Metric | Value |
|---|---|
| Accuracy | 0.9868 |
| Precision | 0.9974 |
| Recall | 0.9780 |
| F1-score | 0.9876 |
| AUC | 0.9966 |

Per-class: Real (precision 0.975, recall 0.997, 3,753 support); Fake (precision 0.997, recall 0.978, 4,364 support). The model is slightly more likely to miss an actual Fake article than to wrongly flag a Real one, though both error rates are small.

Confusion matrix / ROC curve: `evaluation_plots.png` (generated by the notebook).

## Inference

`predict_fake_or_real(text)` (section 7) returns a Fake/Real label and probability for any typed-in sentence. The full `evaluation.csv` run is saved to `evaluation_predictions.csv`.

Notably, an obviously-fabricated hand-written example ("scientists confirm the earth is flat...") was misclassified as Real (p(fake)=0.006) despite the 98.7% held-out accuracy, a useful reminder that the model is picking up on `train.csv`'s specific article style/source patterns rather than genuine claim-level fact-checking, so it may not generalize well to out-of-distribution text. See section 8 of the notebook for the full write-up.
