# Fake News Detection

Binary classifier (Fake / Real) trained on the ACM ML fake-news dataset, with an inference mode for unseen articles.

## Approach

Bidirectional LSTM over a learned embedding (`Embedding → BiLSTM(64) → BiLSTM(32) → Dense → Dropout → Dense(sigmoid)`), chosen over fine-tuning BERT for speed — trains in a couple of minutes on a Colab GPU rather than a much longer fine-tuning run.

## How to run

1. Open `Fake_News_Detection.ipynb` in Google Colab, `Runtime → Change runtime type → T4 GPU`.
2. Get the data into Colab — either:
   - Add the shared "ACM ML FAKE NEWS DATASET" Drive folder as a shortcut in your own Drive, then run the `drive.mount(...)` cell (section 1), or
   - Drag `train.csv`, `test.csv`, `evaluation.csv` straight into the Colab file browser and set `DATA_DIR = '/content'`.
3. Run the "inspect columns" cell first and check the printed column names against `TEXT_COL`/`LABEL_COL` in section 2 — adjust if the actual CSV headers differ (e.g. `article` instead of `text`).
4. `Runtime → Run all`.
